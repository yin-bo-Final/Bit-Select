# UI 交互验收与修复

日期：2026 年 10 月 9 日。基线：`b0af3c9`。分支：`codex/fix-ui-user-journeys`。

本轮通过 computer use 操作本地浏览器，对实际页面流程复现、修复、复测，并进行独立代码交叉审阅。延续现有浅色/深色外观、曲面容器和背景动效，没有重新替换设计系统。

## 已确认并修复的问题

| 问题 | 最终行为 | 浏览器复测 |
| --- | --- | --- |
| 商品、购物袋接受小数数量；精度属性还会使显示值与输入草稿错位 | 保留原文，要求库存范围内的整数；空值、小数、零和超库存值不能购买；回车不能隐式取整 | 商品 `1.5` 回车后仍显示 `1.5`，购买禁用；购物袋失焦后同样保留小数并禁结算 |
| 购物袋更新失败时显示 2 件，结算可能仍提交服务器旧快照 1 件 | 编辑为草稿，失焦/回车保存，步进即时保存；只有草稿与成功同步的快照一致且无行错误才允许结算 | 更新接口返回 503 后显示行内错误，结算禁用；重试成功后合计从 99 元更新至 198 元 |
| 下架商品仍可结算 | 数量操作禁用，保留移除入口，提示先移除再结算；售罄和超库存也阻断 | 用模拟 GET 响应展示下架商品，结算及数量操作禁用 |
| 登录总是返回首页 | 商品、受保护页面和导航登录入口携带本地来源；成功登录返回原页面，拒绝外部地址及登录循环 | 访客从商品 76 点立即选购，登录后返回商品 76 |
| 点击重新回答会清空准备中的下一条问题 | 显式重试或快捷建议保留草稿；只有发送当前输入才清空 | 停止后填写草稿，再点重新回答，草稿保留 |
| 初次请求失败显示无订单、无购物袋、无地址或无售后，掩盖故障 | 失败显示原因与重试，已加载列表保留快照；依赖旧数据的操作禁用 | 分别模拟购物袋、订单、售后和地址的 503；没有误导性空列表提示；恢复后可重试 |
| 分类和知识库读取失败仍可提交依赖数据的操作 | 分类失败禁新建/保存，支持重新加载；知识库未知状态显示“—”，禁同步并支持重新读取 | 两种接口失败均出现具体原因；重试恢复后按钮可用；没有发起真实索引任务 |
| 配送电话只检查是否为空 | 地址簿及结算共用电话校验，拒绝纯符号、纯文字和空白；支持数字、分隔符和开头的加号 | 填入 `abcdef` 后提交停留结算页，显示格式提示 |
| 管理员库存和金额会在失焦时自动取整、舍入或钳位 | 保留原始字符串；金额精确转换为分，最多两位小数；库存为有界非零整数；提交入口二次校验 | 库存 `1.5`、`0`、`-20`（库存 19）、`100001` 均禁用；金额 `0.015`、`100000.01`、`-1`、`1e3` 均禁用；合法值可用 |
| 运维用户 ID 输入会把 1.5 改成 2，超大数精度丢失 | 输入要求正的安全整数，非法值保留、提示并禁筛选；空值清除筛选 | `1.5`、`0`、`9007199254740993` 不可筛选；`1` 和空值可用 |
| 付款失败的确认弹窗产生未处理 Promise 拒绝，触发全局错误浮层 | 使用 Ant Design hook modal 的 await 模式，失败保留弹窗重试；知识库确认同步同样修复 | 零余额付款显示余额不足，弹窗保留；修复后未新增全局异常日志 |
| 多个后台常驻表单共用字段 ID，标签串到其他表单 | 给余额、商品、库存和发货表单独立命名空间 | 余额说明输入的可访问名称由“分配说明 操作原因”恢复为“分配说明” |
| 商品页悬浮导购按钮盖住商品专属导购入口 | 商品页使用自带商品上下文的内联入口，订单页继续保留悬浮入口 | 1280px 商品页的专属导购链接完整可见、不再被重复按钮遮挡 |

订单分页读取失败保留上一次成功页码及列表快照；初次读取失败不显示虚假的订单数 0。地址、售后等读取请求在卸载/切换时取消，避免旧响应覆盖当前状态。

## 响应式与验证结果

11 个页面分别检查 320、390、768、1024、1440px，共 55 个页面/窗口组合：商城、商品、购物袋、订单、账户、登录、导购、商城管理、运行总览、AI 请求追踪、可靠任务队列。DOM 实测文档及 body 宽度均未超过窗口宽度。另检查有商品的手机购物袋、库存弹窗、导购历史抽屉、任务详情、引用及多行草稿；窄屏表格在自身容器内横向滚动。

- 前端测试 46 项通过，包括金额/库存/ID 精度、数量同步、登录回跳安全、SSE 与滚动控制。
- Next.js 类型检查及生产构建通过。
- 仓库编码/凭证检查、排序数据指纹校验及 diff 空白检查通过。
- 独立交叉审阅未发现本轮新增的合并阻断项；GitHub 完整 CI 结果以本分支 PR 检查为准。

本地截图和尺寸记录保存在忽略目录 `.local/ui-journey-20261009/`，不把验收账号凭证提交到仓库。报告不把 DOM 宽度检查等同于所有文字在所有设备上均不会换行。

## 验收边界与测试数据

接口 503、下架商品及带表格/引用的 SSE 回答使用浏览器请求拦截模拟，随后清除拦截；这些结果验证界面恢复和显示，不代表真实供应商故障率或模型回答质量。停止流程有一次真实请求核验，其余富文本显示用模拟 SSE。测试没有进行管理员真实余额分配、发货、退款或索引重建。

验收账号保留一笔已取消的演示订单，零余额支付失败未产生扣款。临时加入购物袋的商品已清空，预留库存已释放；浏览器临时视口和请求拦截在完成后恢复。
