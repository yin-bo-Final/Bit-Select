# 本地使用比特严选

## 现在可以打开

- [商城](http://localhost:3000)
- [AI 导购](http://localhost:3000/assistant)
- [管理后台](http://localhost:3000/admin)

管理员用户名默认 `admin`，密码查看本机 `infra/.env` 中的 `ADMIN_PASSWORD`。文件不会提交到 GitHub。普通账号直接在登录页注册，初始余额为零；管理员在后台“用户与余额”给它分配演示余额。

## 建议体验顺序

1. 注册普通账号，浏览六类商品、商品详情与说明书，加入购物车并填写地址。
2. 用管理员账号分配余额，再用普通账号下单、付款。
3. 管理员发货，普通账号确认收货；也可体验取消、退款和售后申请。
4. 在导购页询问“预算300元，推荐通勤耳机”，展开说明书引用，再追问比较。当前答案与会话都会保存。
5. 明确告诉导购长期购物偏好，等待后台处理后查看个人记忆；可关闭长期记忆或删除单条内容。

本机的200份说明书已经入库。只有更改说明书或在新机器重新初始化时，才需要在管理员后台点击“同步知识库”。

## 重新启动

在仓库根目录打开 PowerShell：

```powershell
pwsh ./scripts/Start-LocalInfrastructure.ps1 -Profile full
pwsh ./scripts/Start-Application.ps1 -Frontend
```

修改后端代码后可加 `-Build` 重新构建。前端第一次安装需要执行 `npm --prefix web ci`。本地已有其他进程占用端口时，启动脚本会提示，不会替你关闭不属于它的进程。

使用 IDEA 调试时，先停止后台应用：

```powershell
pwsh ./scripts/Stop-Application.ps1
pwsh ./scripts/New-IdeaRunConfigurations.ps1
```

在 IDEA 2025.3 或更新版本打开仓库根目录，导入 `backend/pom.xml`，使用 Java 21。脚本已配置 Java 21、Node.js、工作目录与本地环境文件，生成四个后端启动项、`Bit Select - web`、`Bit Select - 全部后端` 和 `Bit Select - 全部应用`。

在 IDEA 停止原先启动的服务与前端，再选择 **`Bit Select - 全部应用`** 点击运行或调试。如果列表尚未刷新，使用“文件 → 从磁盘重新加载所有文件”或重新打开项目。单独启动服务请选择名称以 `Bit Select -` 开头的配置，IDEA 自动创建的 `AiApplication` 等临时项不会自动获得这些设置。

后端启动时通过 IDEA 原生支持读取 `infra/.env` 与根目录 `.env.local`，无需安装 `.env` 插件或手动复制密码。修改已有环境文件后重启服务即可；之后新建 `.env.local` 时重新运行生成脚本。配置文件只保存路径，不包含凭证。前端仅配置网关地址，通过 Next.js 读取自己的 `web/.env.local`。各运行项与端口见 [README](../README.md#启动应用)。业务代码在 Windows 运行，中间件继续保留在 WSL Docker。

若出现 `Access denied for user 'bit_select'`，先确认选中了上述配置，并确认环境文件引用存在。单独在终端运行 `Use-LocalEnvironment.ps1` 不会给已打开的 IDEA 添加变量，不需要因此重置数据库。

## 停止与排查

```powershell
pwsh ./scripts/Stop-Application.ps1
pwsh ./scripts/Stop-LocalInfrastructure.ps1
```

停止会保留数据。Java 日志在 `.local/logs`，模型密钥在本机 `.env.local`。不要把这些私密配置粘贴到 GitHub。

这是可运行的单机演示项目：余额、商品、物流均为演示数据，没有连接真实支付和承运商。详细实现、测试证据及边界见 [实施记录](实施决策与进度.md) 和 [AI 验收](AI实现与验收.md)。
